## ⚠️ The Problem Statement
Nepal's tourism industry is incredibly rich in culture and landscapes, yet suffers from digital fragmentation. Tourists struggle to find reliable, verified local guides and seamless accommodations in one place. Conversely, highly talented local guides and authentic hotel owners lack a unified, modern platform to showcase their services to a global audience. This disconnect leads to missed economic opportunities for local communities and a frustrating, scattered booking experience for travelers.

---

## 💡 Solution Description
**YatraVerse** bridges this gap by providing an all-in-one, state-of-the-art tourism ecosystem. We built a platform that not only functions flawlessly but captivates users from the first second with an immersive 3D cinematic space-to-Earth entry sequence. 

**How we solved it:**
- **Unified Dashboards:** Dedicated, role-based dashboards for Tourists, Guides, and Hotels to manage bookings, track ledgers, and handle jobs effortlessly.
- **Direct Connections:** Tourists can directly view verified guides and destinations, cutting out the middleman.
- **Gamification & Community:** A dynamic Leaderboard system rewards top-performing guides and active tourists, fostering a thriving community.
- **AI Integration:** A built-in AI travel assistant helps tourists plan their perfect Himalayan journey.
- **Premium UI/UX:** A stunning, high-contrast glassmorphism interface ensures the platform feels world-class and engaging.

## 🚀 How to Run Locally

Follow these instructions to get the project up and running on your local machine:

1. **Clone the repository** (or extract the project folder):
   ```bash
   git clone <repository-url>
   cd YatraVerse
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server (Frontend):**
   ```bash
   npm run dev
   ```
   *The frontend will start on `http://localhost:5173` or `http://localhost:5174`.*

4. **Start the Backend Server:**
   Open a new terminal window in the same project directory and run:
   ```bash
   node src/server.js
   ```
   *The backend API will start on `http://localhost:5000`.*
